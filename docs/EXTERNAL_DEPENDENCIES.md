# External dependency register

M0 populates this register from the actual repository. An empty register in the starter pack is not evidence that the eventual product has no external dependencies. Add a row when a capability is selected or introduced; implement adapters only when needed.

| Capability / task | Milestone | Adapter + version | Provider/account owner | Official docs + verified date | Data sent / region | Credential reference | Limits / cost units | Rights / policy | Qualification | Migration / resource binding |
|---|---|---|---|---|---|---|---|---|---|---|

Use references to secrets, never secret values. Record supported operations and known missing features. Distinguish a fake adapter, sandbox verification, and production qualification. Review model/voice/tool dependencies as well as conventional web APIs.

For social publishing, record each platform/account/operation separately. For payment, identity, stored assets, embeddings, workflow engines, and live sessions, link the controlled transition or migration procedure.
