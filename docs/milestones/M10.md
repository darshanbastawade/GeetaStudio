## Implemented behavior

IUniverseRegistry owns dynamic editorial/casting behavior. Closed artifact kinds are bible, character profile, presentation, relationship and episode story; this is not a generic plugin loader. Domain contains owned records; Contracts/Application define typed operations/rules; Infrastructure persists and executes; API composes services and Windows staff pages.

Accepted Geeta defaults are proposed as Draft data from M10-bibles.json against the seven existing core IDs. Dhairy/Neerja remain child leads, Tara teen, Kabir young adult, Meera adult, Dadaji mentor and Shakuni a fictional flawed-reasoning device. Roles are editable data. Neeraja remains an alias of Neerja. Existing canonical names/biographies/life stages/scopes/statuses are preserved. Coach/Guru/Adviser presentations share Shakuni's identity/visual/voice anchors. No name-based application switch exists.

Profiles version traits, goals, flaws, speech, audience/locale eligibility, situation/skill/objective/continuity tags, arc state, aliases and pronunciation/identity guides. Register/edit, validate, activate, retire, duplicate as a distinct identity and promote Guest/EpisodeOnly to Recurring are scoped, audited and idempotent. Same-ID life stage/identity/anchors cannot silently change. Edits reset managed profiles to Draft; promotion keeps the original ID and episode provenance. Existing aliases are retained in the core alias registry.

Casting explains exclusions and returns selected stable IDs, roles, compatible reviewed presentation guides and costs. It supports explicit compatible draft pins, proposes unregistered guests for missing roles, and requires registration before composition. Retired/rejected/foreign/incompatible choices cannot override gates. Production requires stored rights-qualified media references. Distinct-role assignment respects the total budget and reserves pins; it avoids greedy role starvation. A bounded 10,000-step search requires narrowing complex briefs. Two to four speakers is editable guidance, separate from the brief's maximum.

Episode identities have explicit appended story revisions. Each story freezes the bible, brief, character/core/profile revisions, original scope, roles, presentation, approved relationships, arc/guides, continuity and reviewed beats. Editing/promoting/retiring does not rewrite historical manifests. An explicit new revision reissues an episode. A snapshot containing a Draft profile cannot be approved after merely approving that profile: compose a new revision with approved profiles.

Original dialogue/narration is visibly fiction, not scripture/history. Lead roles require agency and trait claims must match profiles. Mandatory forbidden treatment metadata and configured forbidden phrases/attributions cannot be overridden. Humor can be disabled per universe, audience or subject; satire has a visible label and separate editorial escalation, also required for real people/current events. Every story still needs human review. These deterministic metadata/lexical gates supplement human prose assessment; they are not universal semantic classification or human quality evidence.

Real/historical identity requires current reviewed evidence plus an explicit manual identity/likeness/voice/private-history permission reference. A familiar name does not authorize it. Release rejects fixture identity evidence. Presentation/asset references remain owned, scoped and stable. Current byte availability/checksum/owner, source rights and M05 evidence are rechecked; revoked media cannot pass. Release additionally requires manual bible/profile/presentation/relationship/story/escalation qualification, current approved bound content matching all beats, and any linked lesson's M09 export gate. Export is never publication.

Small prerequisite changes: M09 export now participates in an existing parent transaction without nested begin/premature commit. M09 cast excludes EpisodeOnly characters and managed profiles lacking current approval. Legacy M09 fixture behavior remains available. Existing M08 cancellation/admission fences are preserved.
