## Implemented behavior

Application-owned IAnalyticsWorkbench and IChannelAnalyticsProvider, schema analytics.events.v1, immutable source system/account/provider-profile versions, metric definitions, FX evidence, economic events, forecasts and commands. Domain contains only owned data. Infrastructure owns SQL/reporting; Integrations owns deployed validated-import/disconnected fixture normalization; API is the existing composition root. [Contracts](../../src/ContentOS.Contracts/AnalyticsContracts.cs), [rules/ports](../../src/ContentOS.Application/AnalyticsRules.cs), [ledger](../../src/ContentOS.Infrastructure/AnalyticsWorkbench.cs), [reports](../../src/ContentOS.Infrastructure/AnalyticsReports.cs), [capture](../../src/ContentOS.Infrastructure/AnalyticsCapture.cs).

Administrator imports bounded100-entry evidence batches in scoped serializable transactions with tenant locks, stable authenticated operation replay and SourceAudit records. Duplicate source-system/account/event IDs or same kind/economic keys return existing identity only if the exact original financial/event fingerprint matches. A conflicting value/source/account is rejected. This applies across source profile replacements, within a batch, separate requests and concurrent requests. SQL has scoped unique keys/composite foreign keys/rowversions and no immutable UPDATE or DELETE via the API identity. Metrics are bound to original publication platform/account and exact revision/campaign.

Revenue streams include platform payouts, sponsorship, GeetaPlusSubscription, TALK/CREATE credits, books/comics/packs, institutional contracts, content/ContentOS licensing, merchandise and affiliate commerce. Acquisition is a separate explicit dimension; unknown remains visible. Net = gross minus taxes/pass-through/refunds/fees, with surviving refund fees preserving negative net. Estimated revenue stays separate from earned recognition. Linked immutable delayed refunds deduct original revenue and preserve its stream/currency/FX/acquisition; they never rewrite or double-count a sale. Settlements reference original earned revenue/currency/FX/dimensions, cannot exceed the current recognized net, retain unique settlement references and never create additional revenue. Selected-period recognition-minus-settlement is labelled as a period difference, not invoice balance or statutory accounting.

FX records pin immutable source/target/effective/rate/provenance versions. New rates never revalue existing events. Reports can show original currency or a captured target currency; missing conversions are explicitly excluded/countable. No FX rate, actual revenue, tax policy, bank balance or attribution is invented. Financial line items/fingerprints are privately paginated with stable as-of filtering for reconciliation.

Metrics retain definition/unit/aggregation/version, originating system/account, content/publication/campaign and observed exact windows. Delta windows must be disjoint. Repeated Snapshot/Gauge observations append history and select latest per exact window, not sum repeated counters. Different definitions/accounts remain separate; unavailable is null, partial coverage remains explicit. Reports filter occurred time and received-as-of with a10000-entry operational bound rather than silently truncate.

Exact content snapshots retain revision, universe scope, audience/locale, factual/fictional mode, format, bound M15 brief/cluster IDs, core and registry character revisions, campaign/publication and discovery source. Core cast, registry stories and factory casts are all included; no character metrics become viewer/personality claims. Variants show historical distinct approved revision denominator and separately labelled current approval, actual production/review/rework costs, separate overhead, contribution with coverage, first M18 published history time minus revision creation, affected-revision correction rate, scoped engagement and consented observational learning feedback.

Known authoritative zero-price work is captured as zero rather than missing. Episode cost rows bind exact WATCH production and require current master approval independently of script approval, keeping technical fixture review explicit. New controlled real rendering regression verifies zero cost, pending-versus-approved episode denominator, and duplicate capture.

Capture imports completed M7 charges, finalized M16 charges and M17 renderer charges under reserved authoritative keys, keeping original currency and frozen event identity. M16 generated voices/images are not billed again via WATCH summaries. Unknown/uncaptured charges remain visible; unallocated charges stay universe-level. M1 probe usage is dimensionless and is never fabricated as money; staff review minutes and factory budgets are not actual expenses without financial evidence.

Consent records are bounded, purpose-specific, pseudonymous UUID/fixture references with explicit genuine/fixture evidence. Fixture subjects cannot label genuine activity. Consent must precede activity; disable cannot be undone and suppresses linked reporting even for historical queries while finance evidence persists. Cohorts use acquisition-month/channel of the first acquired event in the supplied range, observed conversion, matured30-day return, per-subject learning means, and explicit matched session costs. Five-subject minimum applies to all subaggregates. Reports expose no subject IDs and do not claim causal learning. Missing session/cost/FX evidence yields unavailable results.

Forecast edits append key/versioned audience/conversion/price/retention/period/payout eligibility and rate, media/AI/overhead/review cost and low/high multipliers with evidence. Ineligible platform payout projects zero. The retained-audience formula is inspectable; gross forecasts versus net actual comparison preserves deduction differences. Actual revenue filters both stream and acquisition; cost is channel-wide without invented cross-stream allocation. Missing actuals/FX and uncertainty remain visible; no guaranteed earnings claim.

Private /staff/analytics displays reconciliation, separate dimensions, coverage, variants/casts, metrics, consented cohorts/session costs and inspectable forecasts. Administrator evidence-file/form imports, version administration and owned capture use existing staff authentication/CSRF/no-store/noindex. /api/v1/analytics/tenants/{tenant}/universes/{universe} contains the scoped endpoints. Runtime-disabled M0 remains healthy; existing API/web/Worker composition and permissions preserved. No new background processor is needed.
