## Implemented behavior

Application-owned ITextGenerationProvider, IAiTaskRouter, IAiAdministration and IAiEmbeddingAdapter contracts isolate deployed adapters from tenant/task policy and persistence. Task profiles draft/summarize/translate/evaluate/answer-with-evidence/embedding resolve immutable provider profiles rather than business-code model names. Profiles pin model/options, capabilities, locale/context/output limits, pricing/currency, classification/region/retention/training policy and explicit qualification evidence. At most three qualified profiles comprise one versioned route. Every fallback must satisfy the whole original policy; tools are explicitly unsupported in M07.

M01 runtime provider definitions/connections/capability profiles remain the control plane. AI profiles reference original connection IDs; enable/kill/concurrency/circuit/credential checks apply before calls. New runtime definition seeds do not expand the existing runtime.probe endpoint/adapter whitelist. Route changes affect newly reserved runs; original snapshots, connection/profile IDs, model/settings, task/route/prompt/policy/pricing versions and operation fingerprints remain immutable. Identical generation-operation replay never calls a provider twice; changed input/actor conflicts.

One deployed configurable real adapter, openai.text.v1, implements the fixed official chat-completions protocol with strict generated-text.v1 JSON schema, completion limits, store=false, optional bounded SSE/include_usage, cancellation and normalized errors/refusals. Microsoft.Extensions.AI.Abstractions 10.9.0 chat/usage types stay inside Integrations. Redirects, tools and adapter/SDK retries are disabled. Fixture A/B have independent response/usage implementations and prove offline routing; they do not qualify real-provider fallback. No real account/model profile was configured or called during verification.

Core SQL ai-schema records store immutable profiles/routes/snapshots, route heads, period budgets, runs and attempts. Before submission a tenant transaction lock atomically reserves the sum of every potential fallback ceiling against the run and active tenant/capability/currency-period limit. Conservative byte-based input/protocol allowance and bounded completion tokens cap the estimate. Known charged failures and successful fallbacks settle at their original pricing version; cached input receives its configured discounted rate. USD/INR remain separate, with no FX assumptions.

Unknown/missing/invalid usage, interrupted streams, cancellation after admission and durable Started attempts retain their ceiling and expose UsageUnresolved; unused fallback allowance is released. No fallback follows a policy refusal, quota/configuration denial, cancellation or unknown usage. Streaming uses backpressure and provisional deltas; no provider splice after a delta. Expired interrupted runs can release unsubmitted allowance and mark submitted attempts unknown without resubmission. Explicit authoritative-usage reconciliation is idempotent, retains overages and prevents later admission above the remaining limit. Late completion cannot overwrite an already completed/reconciled run. A remote bill cannot be made transactional with local SQL.

Generation requires owning Administrator membership. Supplied sources must belong to the selected universe and currently permit generation/adaptation/translation/AI processing. answer-with-evidence uses the owned M06 retriever with generation rights, returns no supported match rather than inventing an answer, and never upgrades READ-only Besant material. Returned generated drafts retain source IDs plus current citations/attribution; revoked outputs are withheld on subsequent inspection. GeneratedDraft/GeneratedTranslationDraft are not canonical scripture, reviewed claims or approved publication.

New controlled knowledge indexes request route:embedding. Queueing pins the route/profile IDs into the model reference before computing EmbeddingSpaceId; all corpus/query calls use that exact pinned configuration and report usage through M07. A later active route cannot change an old index's vectors. Cross-model embedding fallback is prohibited. M06 immutable legacy local spaces are retained; the current fully controlled embedding adapter remains the local 128-dimensional L2 reviewed-concept projection, with explicitly zero local-provider rates and no remote processing.

Secured /staff/ai, staff APIs, Blazor link and VS Code demo/benchmark tasks provide working administration/draft/inspection flows. Every POST needs the staff action header, role and actual membership; cross-tenant references fail. Audit and operational logs carry IDs, normalized outcomes and latency, never prompts, raw vendor errors or credentials. Prompts are hashed, not persisted for automated retry; bounded generated outputs remain private application records.
