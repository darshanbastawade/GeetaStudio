## Implemented behavior

Source work/edition/author/translator/publisher/locator and versioned permission records live in the sources schema within CoreDbContext. Snapshots preserve SHA-256, length, retrieval/import timestamps, review state and allowed evidence reference; full text requires retention permission. Dimensions cover languages, territories, formats, commercial/adaptation/translation/AI use, attribution, expiry and revocation. Each edition starts restricted; no inherited translation rights.

Typed application ports own registration, file import, review, intended-use decisions, provenance, exports, publication ledger and revocation/remediation. SQL serializable commands retain authorization and replay locks; operation history and audits commit atomically. Source parties/edition metadata/snapshots/terms/lineage/history are immutable through application persistence. Sources are owning-tenant scoped; global staff role is insufficient.

The staff UI registers works/editions, submits/reviews permissions, imports/reviews files and tracks revocation/remediation. Blazor opens it with browser Windows identity. The API enforces staff policies, membership, action header, rowversion and denied-scope/rights audit. Intake is one strict UTF-8 .txt file up to 64 KiB with checked checksum, never a crawler or arbitrary path loader.

Core exports and approval/public-read boundaries enforce source rights. Exports include every checked revision, deduplicated citations, attribution, checksum/evidence references and typed edges. Revision and asset lineage propagates; new/pending permissions can restrict earlier records. Generated/adapted content cannot bypass adaptation by omitting a flag. Source-derived core imports reject rather than discard provenance. Human review remains responsible for truthful source classification and permission claims.

Revocation/takedown requests target work or edition, identify transitive content/asset dependencies, block new uses and create tasks for affected published ledger entries. Fixture and ReportedExisting modes identify what the ledger means; no external publish/takedown action runs. Manual resolution preserves evidence and does not unblock the revoked source.
