## Implemented behavior

Owned application ports, DTOs and Domain records version proposals across prompts/providers/retrieval/narratives/formats/schedules. Proposals pin hypothesis, scoped adult audience/locale, private cohort, guardrails for correction rate/rework/learning feedback/retention/satisfaction/conversion/cost/failures, sample/case minimums, operation count, currency and deadline. Immutable scoped decision/automation history, serializable tenant locks and authenticated replay preserve evidence. Current M12 baseline/development/held-out checks are required at activation and candidate dispatch. Prompt experiments render the exact registered M08 template revisions from bounded declared inputs; callers cannot replace the template. Evidence-required templates must use the evidence-answer route, preserving the M08 retrieval requirement. Other dimensions retain versioned evaluation/configuration evidence; automatic runtime routing is limited to qualified generation. Fixture measurements remain explicitly synthetic; self-assessment/clicks cannot grant approval.

Private canary and shadow generation use immutable M07 routes. Canary selects the qualified candidate only for the allowed cohort; shadow returns the baseline and separately records candidate output. Only zero-price deployed qualified fixture adapters are enabled in this release. Global route heads and stateful resources are unchanged. Full route ceilings and dispatch credits remain reserved for abandoned/unknown operations. Candidate admission shares the optimization lock, verifies the exact reserved dispatch/actor/operation/route, rechecks current state/deadline before every attempt, cancels in-flight work and fences returned results. Audit records retain hashes and owned IDs, without raw generation inputs. Operation replay is fenced to the original universe. Guardrail/provider/evidence/deadline failures roll back with history; a stopped experiment cannot be reactivated using the same version.

Reports reuse M19's current consent/source-aware ledger, keep measured results/hypotheses separate and costs by currency, report operational failures/current source permission expiry, and retain unavailable coverage. Reviewed dependency/API snapshots record versions, official-documentation references, observation dates and due dates; recommendations require qualification and controlled stateful migration. No network scan or unattended dependency/provider update is performed.

Low-risk commands record cost/provider/rights/failed-job reports and schedule already approved private adult source-free original fiction through the existing CMS. Exact revision/current approval, policy, rights and row-version checks remain authoritative; changed content/children/sensitive source-backed content fail. No approval/publish/payment/credit transfer/migration automation is exposed. Optional API monitor records daily scope reports and stops expired/invalid experiments. UI `/staff/optimization` supplies direct trial/measurement/rollback/report controls, readable results and a separate advanced configuration section. The scoped API and UI use Windows staff authorization, custom action header, no-store/noindex, owned telemetry and existing operational headers.
